## Description
This dataset contains polygon boundaries of developed winter recreation areas operating on the Mt. Hood and Willamette National Forests. This data contains basic attributes to describe the recreation area name and unit location. This dataset was derived by copying the developed recreation boundaries stored within each Forests&#39; corporate recreation GIS dataset.
